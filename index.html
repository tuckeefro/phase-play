Why does it happen?

At the marked stripe, the two wave contributions oppose each other. Together they cancel. Covering one slit removes one contribution, so that spot lights up.

At the center, the contributions reinforce each other. Covering a slit makes that spot dimmer. Blocking light changes the pattern; it does not brighten every part of the screen.

Under the uniform illumination used here, covering half the aperture lets half as much total power through. The numbers above describe intensity at individual points.

Inspect the physics

Fixed experiment: wavelength λ = 550 nm; each slit width a = 30 μm; center separation d = 150 μm; screen distance L = 2 m.

Equal rectangular slits, a coherent plane wave, matched polarization, and classical scalar paraxial far-field propagation. Slit heights are taken as identical; this is the horizontal profile through the pattern.

β = π a x / (λ L) α = π d x / (λ L) sinc(β) = sin(β) / β, with sinc(0) = 1 Both open: I / I₀ = sinc²(β) cos²(α) One covered: I / I₀ = ¼ sinc²(β) I₀ is the two-slit on-axis intensity, fixed for both cases. At x = λL/(2d) = 3.6667 mm: Both open → 0; one covered → 0.2418828.

One approximation has already failed a check. Moving this screen much closer while keeping the far-field formula gives a different profile from a paraxial Fresnel integral. This sketch keeps L fixed.

What could make this a bad activity?
The display invents a surprise.Keep exposure and the intensity reference fixed. Check the blocked and open fields independently. That mathematical check passes at this geometry.
A child learns “blocking makes brighter.”Compare the two spots and ask why their changes differ. A transfer check needs an unseen pattern; the center's result has already been shown.
The marker is too abstract.The same marker links the stripe, graph, and numerical reading. A child should be able to point to the spot without coaching; that is still untested.
The expert view is decorative.Supply exact geometry, normalization, an independent aperture calculation, and a case where the approximation fails. A technical reader should be able to reproduce and challenge them.

This is a review sketch. Browser usability, child enjoyment, and learning have not been established.
